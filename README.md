# Microservice Configuration Repository

Kho lưu trữ cấu hình tập trung (Centralized Configurations) cho hệ thống Microservices của Rikkei Academy.
Sử dụng trong môn học **Microservices in Action**.

## Cấu trúc thư mục
Các file cấu hình được phân bổ theo dạng thư mục `{application-name}` khớp với cấu hình `search-paths` của Spring Cloud Config Server.
